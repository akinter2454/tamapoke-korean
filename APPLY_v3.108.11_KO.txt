TamaPoke v3.108.11 — 개별 타입 배경 적용 / 전체 466px 이별 배경
기준: 사용자가 제공한 v3.108.10 GitHub CLEAN Lightweight

적용
이 ZIP의 내용을 기존 GitHub 저장소 루트에 덮어쓰고 커밋/푸시하세요.
GitHub Actions 빌드 성공 후 기존 방식으로 설치합니다.
PNG를 SD에 복사하지 않아도 배경은 펌웨어에서 바로 표시됩니다.

변경
- 제공된 18개 개별 타입 PNG를 파일 이름과 게임 TYPE 순서에 따라 명시적으로 연결.
- 가로 원본을 종횡비 왜곡 없이 중앙 정사각형으로 crop 후 116x116/16색/4bpp 변환.
- 원형 화면에서 가장자리 일부는 보이지 않습니다. 중앙 정사각형 crop 좌표는 매핑 파일에 기록.
- 466x466 전체 영역을 하나의 배경 좌표계로 표시합니다.
- 기존 464px 표시 후 마지막 2px 덧붙이기 처리 제거.
- 좋은 이별/은퇴 등 ceremony에서도 같은 배경의 전체 세로 영역을 표시.
  y*116/466 방식으로 원본 전체를 균일 확대하며, 하단 한 줄을 길게 늘이지 않습니다.
- 일반 홈은 같은 전체 화면 좌표계의 상단 312행만 갱신하는 기존 최적화를 유지.
- 원본이 116px이므로 확대 픽셀은 약 4px 블록으로 표시됩니다. 네이티브 466px 고해상도 데이터가 아니라 전체 466px에 맞춘 경량 렌더링입니다.
- 배경 데이터 합계 121,680바이트로 v3.108.10과 동일.
- 별도 전체 화면 캐시/PNG 런타임 해독/SD 읽기/동적 메모리 할당 없음.
- v3.108.10의 저장/입력/훈련/상하단 HUD 및 부분 갱신 안정화 코드를 기준으로 유지.

미리보기
previews/ALL_18_ROUND.png: 실제 RGB565 변환 배경 18타입 원형 미리보기.
previews/*_round_466.png: 각 타입 466x466 전체 배경. 좋은 이별 화면도 이 전체 높이 사용.
previews/HOME_EXAMPLES.png: 불/물/풀 타입과 내장 캐릭터의 화면 배치 예시.
배경 픽셀과 확대 좌표는 펌웨어 데이터와 같습니다.
홈 예시의 글꼴/문구/상태값은 설명용 영문이며 실기 캡처가 아닙니다.
게임 언어 설정은 변경하지 않았습니다. 실제 PMD/SD 캐릭터 이미지·동작·날씨에 따라 표시가 달라집니다.

파일
habitat_assets.h / assets/habitats/runtime/*.png: 실제 표시 데이터.
assets/habitats/source/types/*.png: 개별 원본에서 준비한 compact RGB 소스.
assets/habitats/source/type_mapping.json: 한국어 파일명, 타입, 원본 해시, crop 좌표.
원본 고해상도 PNG 18장은 최초 업로드 ZIP에 보존되어 있으며 배포본에는 중복하지 않습니다.
기존 type_atlas.png는 제거했고 생성기는 개별 타입 파일만 사용하도록 변경했습니다.

확인
18개 내장 픽셀 배열과 변환 PNG 인덱스 일치 확인.
전체466/부분312, 낮/밤, fallback, 타입 범위를 포함한 152개 호스트 렌더 경우를 독립 픽셀 기준과 비교 통과.
C++11 컴파일 및 ASan/UBSan 검사 통과. 제한된 환경 때문에 LeakSanitizer만 비활성.
메인/firmware_source 미러 일치. 기존 훈련 검사 42/42 통과.
전체 ESP32 보드 빌드와 실기 재생은 이 환경에서 미실시.
