TamaPoke v3.109.0 — 타입별 낮·노을·밤 독립 배경
기준: 사용자가 첨부한 v3.108.20 MainHUD WhiteText Full466.

적용
이 ZIP의 전체 내용을 기존 GitHub 저장소에 같은 위치로 덮어쓰고 커밋/푸시하세요.
새 habitat_time_assets.h도 반드시 포함해야 합니다. 기존 GitHub Actions가 루트의 모든 .h 파일을 포함해 빌드합니다.
Actions 성공 후 새 펌웨어를 기존 방식으로 설치하세요. 이 패키지는 소스이며 미리 컴파일된 펌웨어가 아닙니다.

동작
기기에 설정된 시계 기준: 낮 06:00–16:59 / 노을 17:00–19:59 / 밤 20:00–05:59.
기존 낮 배경 18장 유지, 노을 18장·밤 18장을 각각 개별 이미지 생성.
한 장의 모음 그림을 분할하지 않았으며, 원래 지형을 참고한 새로운 시간대 그림입니다.
배경의 야간 색상 필터는 제거하고 독립된 이미지를 선택합니다.
시간대 경계에서 하단 캐시도 무효화하여 전체 466행을 갱신합니다.
좋은 이별하기 등 행사에서도 전체 466×466 좌표 방식 유지.
v3.108.20 흰색 상·하단 HUD, 기존 수면/캐릭터 밝기, 세이브 구조 유지.
배경은 시간대별 정지 이미지이며 구간 경계에서 교체됩니다. 기존 날씨 효과는 계속 동작합니다.

기기 부담
실행 데이터는 장당 116×116, 16색, 4bpp, RGB565 팔레트입니다.
추가 플래시 데이터 243,360바이트, 전체 배경 데이터 365,040바이트.
새 화면 버퍼나 런타임 이미지 디코더를 추가하지 않습니다. 현재 시간대의 그림만 읽습니다.
고해상도 생성 원본 PNG는 개발 자료이며 펌웨어에 그대로 들어가지 않습니다.
실제 전체 펌웨어 크기·기기 속도는 Actions 빌드 및 실기에서 확인해야 합니다.

확인
TIME_BACKGROUNDS_PREVIEW.html을 더블클릭하면 오프라인에서 18타입·24시간을 선택할 수 있습니다.
previews/time/에는 실제 16색 변환 결과의 466px 비교 이미지가 들어 있습니다.
배경 전용 미리보기이며 UI/캐릭터/날씨를 합성한 기기 캡처가 아닙니다.
원본: assets/habitats/source/sunset, assets/habitats/source/night
재생성: python3 tools/generate_habitat_times.py
렌더러 검증: python3 tools/verify_habitat_times.py (g++ 및 Pillow 필요)
본 작업 환경에는 Arduino CLI/실물 기기가 없어 전체 보드 컴파일·실기 검증은 수행하지 않았습니다.
