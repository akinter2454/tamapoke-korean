TamaPoke v3.109.3 — 포켓몬 분기 진화 선택

1. 진화 가능한 포켓몬의 후보가 2개 이상이면 자동/랜덤 진화 대신 선택 화면을 표시합니다.
2. 후보는 썸네일 + 이름 + 도감 등록 여부로 표시합니다.
3. 이브이처럼 후보가 많은 경우 한 페이지에 4종씩 표시하고 좌/우 페이지 이동을 사용합니다.
4. 후보를 누르면 마지막 확인창을 거쳐 선택한 포켓몬으로 진화합니다.
5. 후보가 1개뿐이면 기존 진화 확인 UI를 그대로 사용합니다.
6. Pet::evolveTo()가 현재 레벨에서 실제로 가능한 후보인지 다시 검증하므로 UI와 진화 판정이 어긋나지 않습니다.
7. 기존 Pet::evolve()의 탐색 목표/미등록/랜덤 선택 로직은 콘솔 등 비-UI 호출의 fallback으로 유지합니다.
8. 세이브 구조와 저장 키는 변경하지 않습니다.

GitHub Actions의 sync_pmd_catalog.py가 생성하는 EXTRA_BRANCH_* 후보(Bellossom, Slowking, Gallade 등)도 같은 선택 UI에 자동으로 들어옵니다.

9. 로컬/오프라인 컴파일에서도 주요 공식 분기 진화가 작동하도록 CORE_BRANCH를 추가했습니다.
   - 냄새꼬: 라플레시아 / 아르코
   - 슈륙챙이: 강챙이 / 왕구리
   - 야돈: 야도란 / 야도킹
   - 배루키: 시라소몬 / 홍수몬 / 카포에라
   - 개무소: 실쿤 / 카스쿤
   - 킬리아: 가디안 / 엘레이드
   - 토중몬: 아이스크 / 껍질몬
   - 눈꼬마: 얼음귀신 / 눈여아
   - 진주몽: 헌테일 / 분홍장이
   - 도롱충이: 도롱마담 / 나메일
   - 코스모움: 솔가레오 / 루나아라
