# Sprite generation brief
Built-in image_gen, transparent output; no API fallback.
Production pixel-art UI atlas for a cute virtual-pet handheld RPG. Dark navy outline, pastel highlights, isolated readable silhouettes, no background discs or captions.
Subjects: burn/flame, poison/skull, paralysis/bolt, sleep/moon, confusion/spiral, freeze/snowflake; sword/shield/winged-boot with green up and red down arrows; bread, weary face, low battery, bubbly bath, bored face, sleepy face, happy heart-face, training dumbbell, evolution butterfly; all 18 elemental type symbols; gym badge, wild grass, boss crown, battle tower, rival trainer.
Source atlas has 44 icons, extracted by verified alpha-separated row bounds. Source cell coordinates and exact firmware enum order are retained in manifest.json. Runtime sizes: battle 18, home 24, type 18, hub 32.
