This build intentionally uses PMDCollab behavior pixel sprites (AnimData.xml and
behavior animation sheets) for added Pokemon/forms. It does not substitute
static artwork when an animated behavior sprite is unavailable. This build
whitelists only the 37 approved Mega forms listed in MEGA37_SOURCE_MAP.txt plus
the five non-Mega permanent evolution forms listed in POWER_EVOLUTION6_SOURCE_MAP.txt;
other battle-gimmick forms remain excluded.

Please retain the upstream PMDCollab/SpriteCollab attribution and applicable
non-commercial / contributor-credit requirements when redistributing this build
or the generated sprite packs. Contributor-specific credits are available from
the PMDCollab/SpriteCollab project and its generated credit data.
